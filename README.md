# Festa em Festa

Protótipo de website desenvolvido pela Crisora para a Festa em Festa, em Torres Vedras.

Site estático com cinco páginas, imagens locais, animações e formulário que prepara pedidos no WhatsApp. Não confirma reservas nem processa pagamentos. As imagens são ilustrativas.

## GitHub Pages

Em Settings → Pages, selecionar Deploy from a branch, branch `main` e pasta `/ (root)`.

Não necessita de instalação ou compilação.
